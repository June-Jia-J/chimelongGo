## 1. 设计概述

### 1.1 设计目标

在满足需求说明文档全部核心需求的前提下，采用**最小可行实现**策略：架构清晰、模块职责单一、代码简洁可维护，同时符合项目规范中的 Docker 交付、现代 UI、响应式等要求。

### 1.2 技术栈选型

| 层级 | 选型 | 说明 |
|------|------|------|
| 前端基础 | HTML5 + CSS3 + JavaScript | 纯前端，无框架依赖，符合技术栈要求 |
| 样式 | Tailwind CSS (CDN) | 满足项目规范「拒绝原生 HTML 简陋界面」，保持代码简洁 |
| 图表 | ECharts.js (CDN) | 柱状图、饼图、折线图 |
| 部署 | Docker + Nginx | 100% 容器化，一键启动 |
| 数据 | 静态 JSON + localStorage | 纯前端场景下的数据方案 |

### 1.3 项目规范符合性

| 规范项 | 本项目实现方式 |
|--------|----------------|
| Docker All-in-One | 仅前端服务，Nginx 托管静态资源，docker-compose 一键启动 |
| 一键启动 | `docker compose up` 即可访问 |
| 零 Mock 核心逻辑 | 使用结构化 JSON 数据文件，非硬编码字符串 |
| 现代 UI | Tailwind CSS 保证界面现代化 |
| 响应式 | Flex + Grid + Tailwind 响应式类 |
| 端口 | 项目文件夹 1105，前端端口 **3205** |

## 4. 核心功能实现要点

### 4.1 轮播图（carousel.js）

- **无缝轮播**：克隆首尾 slide，切换时瞬间跳转实现视觉无缝
- **自动轮播**：`setInterval`，悬停时 `clearInterval`
- **过渡**：`opacity` + `transform: scale(1.02)`，`transition: 0.4s ease`
- **进度条**：每张图一个进度条，当前项用 `animation` 从左到右填充

### 4.2 导航栏（nav.js）

- **滚动监听**：`window.scrollY > 50` 时给 `nav` 加 `scrolled` 类，背景从透明变实色
- **下划线**：用 `::after` 伪元素，`transform: scaleX(0)` → `scaleX(1)`，`transform-origin: left`
- **下拉菜单**：`max-height: 0` → `max-height: 200px`，`transition`
- **汉堡菜单**：`@media (max-width: 768px)` 隐藏桌面导航，显示汉堡图标，点击展开

### 4.3 目的地卡片

- 悬停：`transform: translateY(-5px)`，`box-shadow` 加深
- 图片：`overflow: hidden`，内层 `img` 悬停 `transform: scale(1.05)`，`transition`
- 文字：`opacity: 0` + `translateY(10px)` → `opacity: 1` + `translateY(0)`

### 4.4 回到顶部

- 显示条件：`scrollY > 500` 时显示按钮
- 点击：`window.scrollTo({ top: 0, behavior: 'smooth' })`
- 悬停：`transform: rotate(360deg)`，颜色变化

### 4.5 搜索联想

- 输入防抖 300ms
- 用 `filter` 对 destinations 做关键词匹配
- 结果区用打字机效果：`setTimeout` 逐字/逐项追加到 DOM

### 4.6 ECharts 图表

- 柱状图：`type: 'bar'`，`xAxis.data` 为城市，`series[0].data` 为数值，维度切换时 `setOption` 更新
- 饼图：`type: 'pie'`，`selectedMode: 'single'` 实现点击放大
- 折线图：`type: 'line'`，`animationDuration: 1500`，`animationEasing: 'elasticOut'` 实现从 0 增长

### 4.7 暗黑模式

- `body[data-theme="dark"]` 时，`:root` 或具体选择器应用深色变量
- 切换：`document.body.dataset.theme = 'dark' | 'light'`
- 持久化：`localStorage.setItem('theme', value)`

### 4.8 图片懒加载

- `img` 用 `data-src` 存 URL，`src` 为空或占位图
- `IntersectionObserver` 监听进入视口时，`img.src = img.dataset.src`

## 5. 加分功能实现策略

| 功能 | 实现方式 | 位置 |
|------|----------|------|
| 文字闪烁 | `@keyframes blink { 0%,100%{opacity:1} 50%{opacity:0} }` | 首页或攻略页标题/强调文字 |
| 省市县联动 | 三个 `select`，省变化时加载市，市变化时加载县，用静态 JSON 数据 | 表单区 |
| 动态密码 | `input type="password"` + 切换按钮，点击改为 `type="text"` 显示 | 登录/咨询表单 |
| 3D 相册 | `transform-style: preserve-3d`，`rotateX/Y` 随 `mousemove` 计算 | 攻略页相册模块 |
| 数字人 | 使用第三方数字人 SDK 或 iframe 嵌入（按需简化） | 首页或攻略页 |
| 本人形象 | 在 footer 或关于区域放置一张开发者照片 | 底部或关于区块 |
| 数字人背景 | 数字人容器加 `background-image` 或 `video` 背景 | 与数字人同容器 |

## 6. Docker 与部署设计

### 6.1 Dockerfile（纯静态站点）

```dockerfile
FROM nginx:alpine
COPY . /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

### 6.2 docker-compose.yml

```yaml
services:
  frontend:
    build: .
    ports: ["3205:80"]
    restart: unless-stopped
```

### 6.3 nginx.conf 要点

- `root /usr/share/nginx/html`
- `index index.html`
- SPA 场景可配置 `try_files`，本项目多页面直接按路径访问即可
