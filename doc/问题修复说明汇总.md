# 长隆旅游网站 - 问题修复说明汇总

> 以下为测试/验收反馈问题的修复说明，便于复盘与答辩参考。

---

## 1. 样式问题

**问题**：轮播图与热门地区（目的地概览）之间的间隔偏大；入口按钮「数据可视化」「旅游攻略」在鼠标悬停时文字颜色变为深蓝，在深蓝按钮背景上几乎不可见；暗黑模式下密码显示/隐藏按钮（#togglePwd）图标与背景对比不足难以辨认；暗黑模式下图表标题与坐标轴文字颜色偏灰不清晰；图表加载时无等待提示，首屏体验差。

**修复说明**：

- **区块间距**：在 `css/layout.css` 中注释掉 `section` 的 `margin-bottom`，并为 `.py-16` 定义为 `padding-top: 2rem`、`padding-bottom: 4rem`，轮播与目的地概览间隔由该内边距控制，避免过大。
- **入口按钮悬停文字**：在 `css/components.css` 中为 `.entry-card:hover` 和 `.entry-card:active` 增加 `color: white`，避免继承全局 `a:hover` 深蓝色导致在按钮上不可见。
- **暗黑模式密码按钮**：在 `css/components.css` 中为 `[data-theme="dark"] .pwd-toggle` 设置浅色背景与边框（如 #4B5563、#6B7280）、文字/图标颜色 #F3F4F6，悬停时略亮，保证可见性。
- **暗黑模式图表文字**：在 `js/charts.js` 中根据 `body[data-theme="dark"]` 为图表 option 设置标题、坐标轴、图例、饼图标签等文字颜色为白色（#FFFFFF），并在主题切换时派发 `themechange` 事件，图表监听后调用 `refreshChartsTheme()` 即时更新，无需刷新页面。
- **图表 Loading**：在 `analytics.html` 增加「图表加载中」遮罩（旋转动画 + 文案），在 `js/charts.js` 中通过 `initAnalyticsCharts` 的 `onAllReady` 在数据与图表就绪后隐藏遮罩，并在 `css/components.css` 中增加 `.chart-loading` 等样式（含暗黑模式适配）。后续针对「Loading 不明显」做了原因分析与视觉增强，见下方第 8 条。

## 2. 页面间跳转未实现显式“平滑过渡动画”

**问题**：需求要求「页面间跳转带平滑过渡效果」，当前仅为普通 `<a href="xxx.html">` 整页刷新，无离场/入场动画。

**修复说明**：

- 在 `css/components.css` 中增加页面过渡样式：`body main` 设置 `transition: opacity`；`body.page-exit main` 离场时 `opacity: 0`；`body.page-enter main` 入场前 `opacity: 0`。
- 新增 `js/page-transition.js`：拦截站内同源且会发生跳转的链接点击，`preventDefault` 后给 `body` 加 `page-exit`，约 220ms 后执行 `location.href`；新页加载时通过内联脚本给 `body` 加 `page-enter`，两帧后移除以触发主体淡入。
- 四个页面（index、destinations、guide、analytics）均增加上述内联脚本并引入 `page-transition.js`，实现「点击 → 当前页淡出 → 跳转 → 新页淡入」的平滑过渡。

## 8. 数据页图表 Loading 不明显

**问题**：数据页（analytics.html）图表加载时的 loading 提示不够明显，用户难以察觉正在加载。

**原因分析**：

1. **加载时间过短**：数据来自本地 `assets/data/chart-data.json`，fetch 几乎瞬时完成，`onAllReady` 随即执行并隐藏 loading，loading 一闪而过，用户很难注意到。
2. **视觉对比不足**：
   - 遮罩背景为 `rgba(255,255,255,0.85)`，在半透明下与页面米色/浅灰背景融合，区分度不高；
   - Spinner 仅 40px、3px 边框，且底圈为 `gray-200`、高亮为 primary，在整页中偏小、偏淡；
   - 文案「图表加载中...」为 0.9rem、`gray-500`，在浅色底上不够突出。
3. **层级与位置**：loading 使用 `position: absolute` 覆盖 `.chart-loading-wrap`，z-index 为 10，层级无问题；但若首屏内容较高，loading 视觉重心可能不在首屏正中，弱化存在感。

**修复说明**：

- **样式增强**（`css/components.css`）：提高遮罩不透明度或使用轻微实色背景，增强与页面背景的对比；将 spinner 尺寸增至 52px、边框加粗至 4px，并强化主色与底圈对比；loading 文案改为更大字号与更深色（如 `gray-700`）；为 loading 容器增加轻微阴影与圆角，使整体更易被识别。
- **最短展示时间**（`analytics.html`）：在 `onAllReady` 中对 `hideChartLoading` 做至少 400ms 的延迟执行，确保即使用户网络很快，loading 状态也能被明确看到，避免「闪一下」的体验。

## 3. 图片懒加载未在页面中真正启用

**问题**：`lazy-load.js` 已实现 `initLazyLoad`（IntersectionObserver + data-src），但页面中无 `data-src`、无 `initLazyLoad` 调用，懒加载未生效。

**修复说明**：

- **首页（index.html）**：开发者头像改为 `data-src="assets/images/developer.jpg"` 并设占位 `src`；目的地卡片由 JS 输出时使用 `data-src`、`src=""`，在渲染后调用 `initLazyLoad('img[data-src]')`；引入 `lazy-load.js`。
- **目的地页（destinations.html）**：`renderDestinations` 中卡片图片改为 `data-src`、`src=""`，设置完 `innerHTML` 后调用 `initLazyLoad('img[data-src]')`；引入 `lazy-load.js`。
- **攻略页（guide.html）**：3D 相册 4 张图及相关攻略卡片图片改为 `data-src`、`src=""`；在 DOMContentLoaded 末尾及相关攻略渲染后调用 `initLazyLoad('img[data-src]')`；引入 `lazy-load.js`。
- 轮播图与攻略封面保留直接 `src`，以保证首屏与 LCP。

## 4. 滚动事件未使用节流优化

**问题**：仅搜索使用了防抖（debounce），导航栏与回到顶部的滚动监听未使用节流（throttle），高频触发可能影响性能。

**修复说明**：

- 在 `js/nav.js` 中：将 `onScroll` 用 `global.Utils.throttle(onScroll, 100)` 包装后绑定到 `window` 的 `scroll` 事件，初始仍执行一次 `onScroll()`；IIFE 传入 `global` 以便使用 `Utils`。
- 在 `js/back-to-top.js` 中：将 `scrollFn` 用 `global.Utils.throttle(scrollFn, 100)` 包装后绑定到 `scroll`，保留一次 `scrollFn()` 做初始状态。
- 节流间隔 100ms；若 `Utils` 未加载则回退为原回调，保证兼容。

## 5. 未使用 \<table\> 展示数据

**问题**：需求要求「设计美观的表格展示数据」，任务清单有表格加分项，但项目中未使用 `<table>` 元素。

**修复说明**：

- 在 **analytics.html** 数据可视化页，在折线图下方增加「热门城市访问量明细」区块，使用语义化 `<table class="data-table">`，含 `<thead>`（排名、城市、访问量）和 `<tbody id="cityVisitTableBody">`，由 JS 根据 `chart-data.json` 的 `cityVisit` 填充，并与「月/季/年」维度按钮联动。
- 在 **js/charts.js** 中：`initAnalyticsCharts` 的 `onAllReady` 传入已加载的 `data`，供页面保存并渲染表格；页面在维度切换时同时更新柱状图与表格。
- 在 **css/components.css** 中增加 `.table-wrap`、`.data-table` 样式：表头主色渐变、斑马纹、行悬停、圆角阴影、暗黑模式适配，实现美观表格展示。

**问题**：目的地卡片要求「文字从下往上渐显」，当前仅有透明度变化，缺少从下往上位移渐显（translateY）效果。

**修复说明**：

- 在 **css/components.css** 中定位目的地卡片内文字容器（如 `.dest-card-title`、描述区域等），为其入场或悬停动画增加 `transform: translateY(...)` 与 `opacity` 的过渡：初始或默认 `translateY(一定正值)` + `opacity: 0`，过渡到 `translateY(0)` + `opacity: 1`，实现从下往上渐显效果（可与现有透明度动画合并）。

## 14. 目的地搜索打字机效果不符合

**问题**：目的地搜索要求「打字机效果逐个显示」，当前实现为「逐条延时追加」，未使用逐字打字机效果（`typewriter()` 已定义但未用于渲染）。

**修复说明**：

- 在 **js/search.js** 中：将联想结果或搜索提示的渲染改为调用已有 `typewriter()`（或等价逐字输出函数），按字符或按词逐字/逐词输出到目标 DOM，而非一次性或逐条延时追加整句；若 `typewriter()` 未在当前联想列表 DOM 上挂载，需把联想项展示逻辑改为通过 `typewriter()` 驱动显示，以实现「打字机效果逐个显示」。

**修复说明**：

## 16. 3D 相册鼠标拖动与 3D 翻页效果不符合

**问题**：3D 相册要求「鼠标拖动 + 3D 翻页效果」，当前为 mousemove 触发旋转跟随，非「拖动」；也无「翻页」交互。

**修复说明**：

- **拖动**：在 **guide.html** 所引用的相册脚本或 **js/** 中，将旋转逻辑由「mousemove 直接跟随」改为「mousedown + mousemove + mouseup」的拖动累积旋转（记录按下时角度，拖动过程中根据位移累加旋转量），实现真正的拖动旋转。
- **翻页**：为 3D 相册增加「翻页」结构（如正反面或前后页）及点击/按钮触发的翻页动画（CSS 3D transform 或 JS 控制翻转角度与过渡），使相册具备「翻页」交互而不仅是旋转。

## 17. 暗黑模式全站配色平滑切换不完整

**问题**：暗黑模式要求「全站配色平滑切换/全局渐变过渡」，当前通过变量覆盖完成配色切换，但缺少对主题切换本身的全局过渡实现。

**修复说明**：

- 在 **css/base.css** 中为受主题影响的属性（如 `color`、`background-color`、`border-color` 等或 `body`/根下使用变量的容器）增加 `transition`（如 `transition: background-color 0.3s, color 0.3s, border-color 0.3s`），或在 **js/dark-mode.js** 切换 `data-theme` 时临时为 `body` 或全局包裹层增加过渡 class，在切换瞬间使全站颜色随 CSS 变量变化产生平滑过渡，而非瞬间跳变。
