## 1. 项目概述

### 1.1 背景与目标

开发一个以长隆旅游为主题的高端现代化旅游网站，作为期末作业交付。网站需在页面内容完整性、CSS 优化、主题突出、布局合理性等方面达到高分标准，并实现丰富的动态交互与数据可视化，体现技术深度。

### 1.2 核心设计原则

- **高端质感**：极简轻奢风格，避免花哨，体现品牌调性
- **技术亮点**：动态效果丰富，数据可视化专业
- **代码质量**：结构清晰，注释完整，性能优化
- **简单可靠**：代码尽量简单，覆盖和实现功能即可

## 2. 核心需求详述

### 2.1 整体设计风格

| 需求项 | 具体要求 |
|--------|----------|
| 视觉风格 | 极简轻奢现代化设计，莫兰迪配色：主色 `#1E3A8A`、暖米色 `#F5F0E1`、辅助色 `#E2D9C8`，简洁留白与层次感 |
| 布局结构 | Flex + Grid 结合，统一模块：头部导航、主体内容、底部版权/联系方式，统一视觉规范（间距、字体、圆角） |
| 响应式 | 兼容 PC（1920/1366px）、平板（768px）、手机（375/414px），导航栏移动端转为汉堡菜单 |

### 2.2 动态交互功能

#### 2.2.1 核心动态效果（必做）

| 功能 | 实现要求 |
|------|----------|
| 首页轮播图 | 无缝自动轮播；鼠标悬停暂停；支持手动切换；进度条/指示器动画；切换时淡入淡出+轻微缩放过渡 |
| 导航栏 | 滚动时背景从透明渐变到实色；选中/悬停项下划线从左到右滑动；下拉菜单（如目的地分类）缓动展开 |
| 目的地卡片 | 悬停时卡片上移 5px、阴影加深；图片轻微放大；文字从下往上渐显 |
| 回到顶部 | 滚动超过 500px 时渐显；点击平滑滚动回顶部；悬停旋转+变色动画 |

#### 2.2.2 创新动态功能（加分项）

| 功能 | 实现要求 |
|------|----------|
| 目的地搜索 | 输入关键词实时联想匹配；防抖处理；搜索结果打字机效果逐个显示 |
| 天气联动 | 调用免费天气 API（如 OpenWeatherMap）；选择目的地后显示当地天气；动态天气图标（晴/雨/雪等帧动画） |
| 3D 旅游相册 | CSS 3D 变换；鼠标拖动相册卡片随角度旋转；模拟 3D 翻页效果 |
| 暗黑模式 | 开关按钮；全站配色平滑切换；localStorage 记住用户选择 |

### 2.3 数据可视化模块

| 图表类型 | 内容 | 交互要求 |
|----------|------|----------|
| 柱状图 | 2025 热门旅游城市访问量 | 悬停显示数值+高亮；可切换月/季/年维度 |
| 饼图 | 出游方式占比（飞机/高铁/自驾/其他） | 点击扇区放大突出；图例筛选 |
| 折线图（加分） | 近 12 个月旅游热度趋势 | 动态数据加载动画（从 0 增长到实际值） |

**实现方式**：使用 ECharts.js，基于旅游相关模拟数据。

### 2.4 页面要求

| 序号 | 页面 | 功能要点 |
|------|------|----------|
| 1 | 首页 | 轮播图、目的地概览、数据可视化入口、攻略入口 |
| 2 | 目的地列表页 | 目的地卡片列表、搜索、分类筛选、天气联动入口 |
| 3 | 攻略详情页 | 攻略正文、图片/视频、相关推荐、咨询表单 |

**页面跳转**：带平滑过渡效果。

## 3. 工程架构

### 3.1 整体架构

```
长隆旅游网站
├── 静态资源层（HTML/CSS/JS）
├── 模块化脚本层（轮播/可视化/交互/API）
├── 数据层（模拟数据 / localStorage / 天气 API）
└── 容器交付层（Docker + Nginx）
```

### 3.2 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端基础 | HTML5 + CSS3 + JavaScript | 纯前端，无框架依赖 |
| 样式增强 | Tailwind CSS（CDN）或原生 CSS | 满足现代 UI 要求，可选 |
| 图表 | ECharts.js | 柱状图、饼图、折线图 |
| 部署 | Docker + Nginx | 容器化交付，一键启动 |
| 数据 | 模拟 JSON + localStorage | 纯前端无后端时的数据方案 |

### 3.3 目录结构建议

```
chimelong-tourism/
├── index.html              # 首页
├── destinations.html       # 目的地列表
├── guide.html              # 攻略详情（支持参数区分不同攻略）
├── analytics.html          # 数据可视化
├── css/
│   ├── base.css            # 通用样式、变量、重置
│   ├── layout.css          # 布局样式
│   ├── components.css      # 组件样式（卡片、按钮、导航等）
│   └── pages/              # 各页面专属样式（如需要）
├── js/
│   ├── carousel.js         # 轮播逻辑
│   ├── nav.js              # 导航交互（滚动、下拉、汉堡菜单）
│   ├── charts.js           # ECharts 数据可视化
│   ├── search.js           # 搜索联想与防抖
│   ├── weather.js          # 天气 API 调用
│   ├── dark-mode.js        # 暗黑模式切换
│   └── utils.js            # 工具函数（防抖、节流、懒加载）
├── assets/
│   ├── images/             # 图片资源
│   ├── icons/              # 图标
│   └── data/               # 模拟数据 JSON
├── docker-compose.yml
├── Dockerfile
└── README.md
```

## 4. 模块划分

### 4.1 页面模块

| 模块 | 文件 | 职责 |
|------|------|------|
| 首页 | index.html | 轮播、目的地概览、入口导航 |
