# 长隆旅游网站 - 项目开发轨迹

> 从需求分析到项目完成的完整过程记录，便于复盘与交接。

---

## 一、项目背景与目标

- **项目名称**：长隆旅游网站  
- **目标**：打造一个符合期末作业高分标准的长隆主题旅游展示站，具备现代官网级的视觉与交互、完整四页结构及 Docker 一键交付。  
- **技术栈**：HTML5 + CSS3 + JavaScript（原生）+ Tailwind CSS（CDN）+ ECharts；部署为 Docker + Nginx（端口 3205）。

## 五、开发实施阶段

### 5.1 按清单从零实现

- 严格按《开发任务清单》从阶段一到阶段七顺序推进。  
- **骨架与样式**：创建完整目录结构；`base.css` 设计令牌与重置；`layout.css` 容器与断点；`components.css` 组件样式；四个页面语义化结构并统一引入 CSS/JS。  
- **导航与布局**：`nav.js` 实现滚动透明→实色、下划线动画、移动端汉堡菜单；统一 footer；四页之间跳转链接完备。  
- **首页**：`utils.js`（debounce、throttle、scrollToTop 等）；`carousel.js` 无缝轮播、悬停暂停、指示器与进度条、淡入淡出+缩放；`back-to-top.js`；首页轮播与目的地概览卡片；`destinations.json` 与卡片渲染。  
- **目的地与数据**：`search.js` 防抖、联想、打字机效果；目的地页搜索区+列表区、按数据渲染；`chart-data.json`、`charts.js`（柱状/饼/折线）、analytics 页与维度切换。  
- **攻略页**：`guides.json`、根据 `?id=` 加载攻略、封面与正文、3D 相册（CSS 3D、鼠标跟随）、咨询表单、相关推荐。  
- **加分与优化**：`weather.js`（Open-Meteo API）、`dark-mode.js`（localStorage）、`lazy-load.js`（IntersectionObserver）、动态密码、开发者形象等。  
- **Docker**：Dockerfile（nginx:alpine）、nginx.conf、docker-compose（端口 3205）、.dockerignore/.gitignore；本地 `docker compose up --build` 验证通过。

### 5.2 实现要点摘要

- 目的地列表首次展示：由 search 的 fetch 或 destinations 页的 fetch 任一完成即可渲染。  
- 数据与展示分离：页面通过 JSON 动态渲染，便于维护与扩展。  
- 无后端：纯静态站，表单提交、天气等均为前端逻辑与第三方 API。
